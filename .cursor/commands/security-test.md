Crie testes de regressão de privacidade/qualidade com dados sintéticos.

**Escopo:** $ARGUMENTS

Use `@40-testes-dados.md` e `@20-privacy-lgpd.md`.

Cobrir preferencialmente:

- ausência de colunas restritas na saída exportável;
- documentos tratados como texto;
- linha inválida segregada com motivo;
- agregação de pacientes distintos correta.

Não use registros reais.
